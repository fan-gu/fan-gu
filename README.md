## Featured projects

### MIRAI — Market Intelligence for Risk AI

A synthetic-data market-risk cockpit with hierarchy drill-down, VaR and P&L analysis, stress scenarios, controls and an auditable AI assistant.

[Live demo](https://market-intelligence-risk-ai.streamlit.app/) · [Code](https://github.com/fan-gu/Market-Intelligence-for-Risk.AI) · [Architecture](https://github.com/fan-gu/Market-Intelligence-for-Risk.AI/blob/main/docs/architecture.md) · [Tests](https://github.com/fan-gu/Market-Intelligence-for-Risk.AI/tree/main/tests)

[![MIRAI risk cockpit](https://raw.githubusercontent.com/fan-gu/Market-Intelligence-for-Risk.AI/main/docs/screenshots/overview.png)](https://market-intelligence-risk-ai.streamlit.app/)

**Implemented:** Python, Streamlit, FastAPI, Pydantic, SQLite, Gemini API, pytest and GitHub Actions. The API is available to run locally; document RAG and LangGraph orchestration remain planned for MIRAI.
